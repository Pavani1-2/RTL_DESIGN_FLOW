# Physical Design Results — Reference Study

> **Reference-only evidence:** This page links to published screenshots from the public [RTL_Workshop repository](https://github.com/madapaamrutha-svg/RTL_Workshop/blob/main/PD-Module-1/README.md). These images are included for comparison and study. They are **not results generated by this repository**, and they must not be presented as measurements from our own RTL design.

## Reference flow
The reference project documents a SKY130/OpenLane physical-design flow covering:

1. Floorplanning
2. Power planning
3. Standard-cell placement
4. Clock-tree synthesis (CTS)
5. Routing
6. Antenna checking and repair
7. Static timing analysis (STA)
8. Parasitic extraction (SPEF)
9. Logic equivalence checking (LEC)
10. Physical verification, including DRC/LVS where supported
11. Configuration/design-space exploration

## What the metrics mean

| Metric | Interpretation | Evidence needed for our design |
|---|---|---|
| Cell area | Total mapped/placed cell area as defined by the report | Our own synthesis or physical-design report |
| Cell count | Number of cells in the implementation | Our own tool report |
| Utilization | Fraction of core area occupied by cells | Our own floorplan report |
| Timing / slack | Whether constrained paths meet timing | Our own STA report and constraints |
| Routing | Status of physical interconnect implementation | Our own routing logs/reports |
| DRC / LVS | Layout-rule and connectivity checks | Our own physical verification reports |
| Antenna | Antenna-rule checking and repair status | Our own flow logs/reports |

## Reproduction status
Our repository currently contains small Verilog examples (counter, MUX, full adder, and decoder), testbenches, and Yosys scripts. The reference screenshots do not establish that these designs have been run through OpenLane/SKY130. To claim equivalent measured results, first select a compatible top-level design, PDK, and constraints, then run the flow and replace this reference-only evidence with reports produced by that run.
