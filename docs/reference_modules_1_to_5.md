## Results interpretation
Physical-design reports commonly include cell area, cell count, utilization, timing slack, routing status, parasitic data, DRC, LVS, and antenna checks. These values depend on the exact design, configuration, PDK, libraries, constraints, and tool versions. Consult the linked original module for the reference report context; do not copy numerical metrics into this project's own results log as if they came from a run of our design.

## Our repository's implementation status
This repository currently includes Verilog examples (counter, MUX, full adder, and decoder), testbenches, and Yosys scripts. The linked reference screenshots document the broader SKY130 physical-design learning workflow; running our own design through that flow remains a separate implementation task.
